## Instalação
### 1. Obter os arquivos executáveis do projeto via GitHub:
Primeiramente, será necessário obter os arquivos do projeto, o que pode ser feito baixando o arquivo "Linhas Cruzadas - Executável.zip", na pasta principal do projeto.

### 2. Descompactar o jogo
Em sequência, você pode descompactar a pasta dos arquivos do jogo.

<div align='center'>
  <img width="400" height="auto" alt="image" src="https://github.com/user-attachments/assets/1aceb506-c178-423f-8de0-f2aacfecc4c2" />
</div>

Após a descompactação, aparecerão três arquivos, sendo um deles o executável (.exe). Assim que clicar no executável, o jogo abrirá!

> ⚠ O sistema de Segurança do Windows pode abrir uma janela de aviso após a tentativa de execução. Nesse caso, você só precisa clicar em <b>"Mais Informações"</b> e logo abaixo aparecerá a opção <b>"Executar mesmo assim"</b>.
